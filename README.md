# Retail Sales & Customer Analytics Dashboard

## Project Overview
An interactive Power BI dashboard designed to explore retail sales performance, customer behavior, product performance, seasonal trends, and delivery time.

## Objectives
- Monitor key retail business KPIs.
- Explore product categories, brands, and sales performance.
- Analyze customer and country-level order patterns.
- Review seasonal sales trends and delivery performance.
- Present insights through interactive visual reports.

## Tools & Skills
- Microsoft Power BI
- DAX
- Data Analysis
- Data Visualization
- Business Intelligence
- Dashboard Design

## Dashboard Highlights
- Retail sales and KPI overview
- Product and category analysis
- Customer and geographic analysis
- Seasonal trends
- Delivery time analysis

## Project File
Add the Power BI file to this repository:
`Retail-Sales-Analytics.pbix`

## How to View
1. Download the `.pbix` file from this repository.
2. Open it in Microsoft Power BI Desktop.
3. Explore the report pages and interact with available filters and visuals.

> GitHub does not display interactive Power BI reports directly. The `.pbix` file must be opened in Power BI Desktop.
